    TemenCAD API

    Your script is JavaScript. Return a shape (or an array of shapes), or call show(shape). Units are millimetres, Y is up, the build plate is y = 0. Every operation returns a new shape; nothing is mutated.

    3D primitives

    box(w, h, d)                 roundedBox(w, h, d, r, { edges: 'all' | 'vertical' })
sphere(r)                    cylinder(r, h)   cylinder({ r1, r2, h })   cone(r, h)
torus(r, tube)               prism(sides, r, h)   polygon([[x,y], ...], h)
polyhedron(points, faces)    loft([sk1, sk2, ...], height | [y1, y2, ...])
text3d('Hi', { size, height, align })

    2D sketches → 3D

    circle(r)  rect(w, h)  roundedRect(w, h, r)  slot(length, r)  regularPolygon(n, r)  polygon2d(pts)
sk.translate(x, y)  sk.rotate(deg)  sk.scale(x, y)  sk.mirror('x')  sk.add/subtract/intersect/hull(other)
sk.resize([w, h], { auto })                                 // scale to a bounding-box size
sk.offset(delta, { join: 'round' | 'miter' | 'square' })   // grow (+) or shrink (−) a 2D region
sk.fillet(r)  sk.chamfer(d)                                 // round or cut every corner
text('Hi', { size, font, align, letterSpacing })           // 2D text, baseline at y = 0
// fonts: 'Inter' (default), 'Inter Bold', 'Nunito Bold' (rounded), 'Source Serif 4', 'JetBrains Mono'
extrude(sk, h, { center, twist, scale })      // up along Y;  sk.extrude(h, opts)
revolve(sk, { angle, segments })              // around Y, sketch x = radius;  sk.revolve(opts)
roof(sk, { angle: 45, tolerance: 0.01 })      // height = distance to the outline: pyramid / hip roof;  sk.roof(opts)
projection(s)  projection(s, { cut: true | y })   // 3D → 2D: footprint seen from above, or the slice at y;  s.projection(opts)

    Transforms (return a new shape)

    s.translate(x, y, z)   s.rotate(xDeg, yDeg, zDeg)   s.scale(f | x, y, z)   s.mirror('x')   s.color('#f80')
s.onPlate()   s.center()   s.centerXZ()   s.align({ x: 'min' | 'center' | 'max', y, z }, [tx, ty, tz])
s.resize([w, h, d], { auto })   // scale to a bounding-box size; 0 keeps an axis, auto scales it proportionally

    Booleans, hull, Minkowski

    union(a, b, ...)   difference(a, b, ...)   intersect(a, b)   hull(a, b, ... | [x,y,z] points)
a.add(b)  a.subtract(b)  a.intersect(b)  a.hull(b)      // arrays of shapes are accepted everywhere
minkowski(a, b)  a.round(r)  a.erode(t)                 // round() = Minkowski with a sphere
shell(a, t, { open: 'top' | ['top', 'front'] })  a.shell(t, opts)   // hollow to a wall thickness

    Arrays (return arrays; wrap in union() to merge)

    linearArray(s, count, [dx, dy, dz])   polarArray(s, count, { radius, axis, start, sweep })
grid(s, [nx, nz], [dx, dz])

    Screw helpers (cutters to subtract; axis Y, top surface at y = 0)

    screwHole('M3', length, { type: 'clearance' | 'tap' | 'countersunk' | 'counterbore', tolerance })
nutPocket('M3', { depth })   heatInsert('M3', { depth })   screw('M3') → { d, clearance, head, csk, nut, insert, tap }
Sizes: M2 M2.5 M3 M4 M5 M6 M8

    Named parts

    s.name('lid')        show(s, { name: 'lid', ghost: true })      return { body, lid }   // keys become names
s.ghost()            // transparent reference, never exported
s.hide()             // listed in the Parts panel but not drawn until you switch it on
// The Parts panel (top right of the viewport) toggles visibility, ghosts, solos (double-click) and exports each part.

    Projects and imports

    // A project is a .temen file (a zip). main.js is the entry; other files are added with the + button above the editor.
import { lid, WALL } from './lid.js';      // lid.js:  export const WALL = 2;  export function lid(r) { ... }
import logo from './Logo.ttf';             // a font in the project: text3d('Hi', { font: logo })
import part from './part.stl';             // a mesh in the project, as a Shape (Z-up STL becomes Y-up)
// Imports work like normal JavaScript modules; only main.js may use a top-level return.

    Helpers

    show(shape)  log(...)  s.bounds()  s.volume()  s.surfaceArea()  deg(rad)  rad(deg)  Math.*
echo(a, b, { w, h })        // console: ECHO (line 12): 1, "x", w = 10, h = 2 — returns a, so echo() works inline
assert(cond, 'message')     // stops the build with an error on that line when cond is falsy; returns cond

    Geometry kernel: Manifold (C++ via WebAssembly). All output is watertight.

    Units are millimetres, Y is up, the build plate is y = 0. Every operation returns a new shape; nothing is mutated.
